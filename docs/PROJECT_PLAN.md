# Разбор идеи и выбор MVP

Дата: 12 октября 2026 года.

## Что строим

Локальную библиотеку по ролику dzen.guru: видео, отдельное аудио, машинная расшифровка с таймкодами и HTML-учебник. Учебник объясняет работу над контентом для Дзена и отдельное практическое задание — создание HTML-сайта при помощи AI-агента. Это две связанные, но разные задачи: в ролике показано производство статей, а не разработка сайта.

Пользователь уточнил: JavaScript не является обязательным требованием. Основа задания — создание HTML-сайта и работа с материалами. JavaScript используется в готовом учебнике для поиска и прогресса; в учебном задании он необязателен.

## Варианты реализации

| Вариант | Стек | Результат | Оценка |
|---|---|---|---|
| **1. Статический учебник — выбранный MVP** | Python, yt-dlp, ffmpeg, локальный GigaAM; HTML/CSS/JavaScript | Локальные файлы, главы, поиск в расшифровке, видео с переходом по таймкодам, прогресс чтения | 4–8 часов плюс время распознавания |
| 2. Локальное приложение для любых роликов | Python/FastAPI, SQLite, HTML/JS, очередь фоновых задач | Ввод URL, очередь скачивания, версии учебника, обработка нескольких видео | 2–4 рабочих дня |
| 3. Платформа учебных материалов | Веб-интерфейс, API, PostgreSQL, объектное хранилище, очередь | Несколько пользователей, доступы, редактор, серверное распознавание | 1–2 недели для ограниченного пилота |

Оценки инженерные, для одного разработчика и одного языка; не являются обещанием срока. В выбранном варианте нет сервера приложений, базы данных и платного LLM. Текст учебника и выводы пишет Codex. XMLRiver применяется для небольшого поиска официальных материалов, результаты сохранены.

## Почему идея жизнеспособна

Скачать доступное видео, извлечь звук, распознать русскую речь и собрать самостоятельный сайт технически возможно. Это подтверждено полученным видео и запущенным локальным распознаванием. Такой MVP полезен как личное учебное пособие. Доходность каналов из рекламного ролика не подтверждает коммерческую жизнеспособность будущей сетки каналов.

## Риски и решения

- **Ошибки распознавания.** Имена инструментов и числа искажаются. Сырой транскрипт сохраняется отдельно; в объяснениях исправляются термины, сомнительные суммы не превращаются в факты. Таймкоды относятся к фрагментам, а не к каждому слову.
- **Неподтверждённая экономика.** Доходы, просмотры и обещания автора — его заявления. Учебник предлагает измеримый небольшой эксперимент и собственный учёт расходов.
- **Изменение правил Дзена.** Официальная справка оказалась недоступна для проверки. Порог подключения и тариф за просмотры не зафиксированы как актуальное правило; их нужно смотреть в студии своего канала перед запуском.
- **Чужие материалы.** Работа с конкурентами должна давать собственные темы и наблюдения. Полные чужие статьи не копируются в учебник. Авторские ранбук и сборщик не получены через регистрацию; вместо них подготовлены собственные шаблоны.
- **Изменение плеера.** Ссылка Kinescope найдена в HTML страницы; прямые адреса потока могут устаревать. Для повторного скачивания используется исходная страница видео, не временный CDN-адрес.
- **Время и место.** GigaAM работает на CPU, время зависит от машины. Расшифровка сохраняет прогресс по фрагментам. Перед скачиванием проверено свободное место.
- **Состояние браузера.** Прогресс чтения хранится на этом устройстве; при запрете localStorage сайт остаётся доступен, но прогресс не сохраняется.

## Структура

```text
IDEA.md                         исходная задача
PROJECT_PLAN.md                 варианты, стек, оценки и риски
README.md                       запуск и повторение обработки
.env / .env.example             только XMLRiver, ключи не публикуются
index.html                      готовый учебник
assets/style.css                оформление и мобильная версия
assets/app.js                   главы, поиск, прогресс, таймкоды
assets/transcript.js            встроенная расшифровка для file://
content/chapters.json            авторские главы и источники
scripts/build.py                сборка сайта из глав и транскрипта
scripts/pipeline.py             скачивание → аудио → GigaAM → сборка
scripts/serve.py                локальный просмотр с перемоткой видео
scripts/research.py             поиск официальных источников
src/services/xmlriver_client.py изолированный клиент XMLRiver
data/source/                    сохранённая страница и метаданные видео
data/media/lesson.mp4            видео
data/media/lesson.flac           аудио, 16 кГц, моно
data/transcript/lesson.*         TXT, SRT, JSON, прогресс JSONL
data/research/                   результаты поиска и XML
examples/first-site/             отдельный рабочий пример HTML/CSS/JS
templates/                      ТЗ, контент-план и редакционная проверка
```

## Критерии готовности MVP

Видео содержит звук, длительность аудио совпадает с видео. Расшифровка покрывает всю запись и имеет TXT/SRT/JSON. Учебник открывается локально; поиск показывает реальные фрагменты и умеет переходить к видео. Главы содержат упражнения и проверяемый результат. Пример сайта имеет работающую кнопку и мобильную версию. Источники и ограничения ясно обозначены.
