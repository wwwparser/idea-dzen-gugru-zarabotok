# От видео к своему проекту

Готовый локальный HTML-учебник по ролику «Claude Code + ДЗЕН = ₽1,024,389». Задача из IDEA.md выполнена в этой папке: видео скачано, аудио извлечено, русская речь распознана локально, подготовлены восемь авторских глав и рабочий пример сайта. JavaScript в учебном задании необязателен.

## Открыть

Дважды щёлкните `index.html`. Интернет для чтения и просмотра скачанного видео не нужен. Расшифровка встроена в `assets/transcript.js`, поэтому поиск работает и без веб-сервера. В браузерах, запрещающих хранение для локальных файлов, отметки глав могут не сохраняться.

При необходимости запустите из этой папки:

```powershell
python scripts/serve.py
```

Откройте `http://127.0.0.1:18763`. Для остановки нажмите Ctrl+C. Сервер поддерживает частичные запросы для перемотки видео. Если порт занят или запрещён системой, используйте `python scripts/serve.py --port 18764` и измените порт в адресе. Обычный `python -m http.server` пригоден для текста, но перемотка больших видео в нём может не работать.

## Что подготовлено

- `index.html` — восемь глав, задания, карта видео, поиск расшифровки, отметки прогресса.
- `data/media/lesson.mp4` — видео в 480p со звуком.
- `data/media/lesson.flac` — отдельная аудиодорожка, 16 кГц, моно.
- `data/transcript/lesson.txt` — машинная расшифровка с таймкодами.
- `data/transcript/lesson.srt` — субтитры по фрагментам.
- `data/transcript/lesson.json` — 63 сегмента, покрывающих запись.
- `data/transcript/lesson.jsonl` — прогресс для повторного запуска GigaAM.
- `content/chapters.json` — редактируемые авторские главы.
- `examples/first-site/` — самостоятельный пример HTML/CSS с необязательной кнопкой на JavaScript.
- `templates/` — задание на сайт, редакционная проверка и CSV контент-плана.
- `PROJECT_PLAN.md` — три варианта реализации, стек, сроки, риски и структура.
- `data/research/` — сохранённые результаты четырёх поисковых запросов XMLRiver.

## Повторить сборку

Для сборки из уже готовых файлов нужен только Python:

```powershell
python scripts/build.py
```

Скрипт читает главы и финальный JSON транскрипта. Если распознавание ещё не закончено, сборка завершится ошибкой об отсутствующем файле. Изменяйте главы в `content/chapters.json`, затем пересобирайте HTML; ручные правки `index.html` при сборке заменяются.

## Повторить обработку видео

Нужны доступные в PATH `yt-dlp`, `ffmpeg`, `ffprobe`, Python с установленным `gigaam` и скрипт локального навыка:

```powershell
$env:OMP_NUM_THREADS='4'
$env:MKL_NUM_THREADS='4'
$env:PYTHONIOENCODING='utf-8'
python scripts/pipeline.py
```

Если видео уже скачано:

```powershell
python scripts/pipeline.py --skip-download
```

Если навык находится в другом месте:

```powershell
python scripts/pipeline.py --skip-download --transcriber C:/path/to/transcribe.py
```

Скрипт запускает доверенный локальный транскрибер GigaAM из `C:/Users/Yuri/.codex/skills/gigaam-transcribe/scripts/transcribe.py`, проверенный перед использованием. Он не хранит его копию в проекте. Повторный запуск использует JSONL прогресса. Не заменяйте исходную аудиозапись другим роликом с тем же именем при существующем прогрессе: для нового ролика нужна отдельная папка результата.

Модель работает на CPU. Исходные файлы не передавались облачному сервису распознавания; платные LLM не вызывались. Скрипт загрузки проверяет наличие не менее 1,5 гигабайта свободного места.

## Повторить поиск

Клиент требует `requests`. XMLRiver-код изолирован в `src/services/xmlriver_client.py`. Заполните `.env` по `.env.example`. Реальные значения не включайте в репозиторий.

```powershell
python scripts/research.py
```

Для каждого запроса — первая страница Google, Россия, русский язык. Успешный XML кэшируется, каждый разобранный запрос сохраняется в JSON. Кэш предотвращает повторную оплату уже выполненного запроса. Четвёртый уточняющий запрос о монетизации сохранён отдельно и не входит в основной список повторного запуска.

## Ограничения материалов

Расшифровка машинная и содержит ошибки терминов и чисел. Таймкоды относятся к фрагментам до 24 секунд. Авторские главы пересказывают механику своими словами и не являются копией закрытого комплекта dzen.guru. Его ранбук и сборщик системы не получены.

Видео рассказывает о статьях для Дзена; глава о создании HTML-сайта — самостоятельная практика по задаче пользователя. Доходы автора, фиксированная выручка за просмотры и сроки подключения монетизации не подтверждены независимо. Официальная справка Дзена не была доступна для проверки, поэтому актуальные пороги в пособии не приводятся.

Источники: [исходная страница](https://dzen.guru/video-claudecode), [официальная документация Claude Code](https://code.claude.com/docs/en/best-practices), [MDN: HTML](https://developer.mozilla.org/ru/docs/Learn_web_development/Getting_started/Your_first_website/Creating_the_content), [MDN: CSS](https://developer.mozilla.org/ru/docs/Learn_web_development/Getting_started/Your_first_website/Styling_the_content). Подробные ссылки — в главе 08.

Проект не опубликован на хостинге. Видео и материалы подготовлены для локального изучения.

## Выполненные проверки

- Видео имеет видеопоток и аудиопоток; отдельный FLAC — аудиопоток. Обе записи длятся 1414,784 секунды; финальный сегмент расшифровки заканчивается на этой же отметке.
- Проверены уникальность HTML-id и наличие всех локальных целей ссылок.
- Python-файлы прошли проверку синтаксиса, JavaScript — `node --check`.
- В Chrome проверены поиск фразы, отсутствие совпадений, сохранение отметки после перезагрузки и сброс прогресса.
- После добавления сервера с Range проверен переход по таймкоду к 22:35 и воспроизведение соответствующего момента. Частичный HTTP-запрос возвращает 206 и правильный диапазон.
- При мобильной ширине 390 пикселей общая страница и пример не имеют горизонтального переполнения; блоки кода прокручиваются внутри своих границ.
- В отдельном примере проверена работа кнопки выполнения задания.

Прямое открытие через `file://` не проверено браузерной автоматизацией: политика инструмента разрешает только HTTP и HTTPS. Статический сайт не использует fetch или загрузку данных через API, но подтверждённый браузерный способ просмотра — `python scripts/serve.py`.
